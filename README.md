# Cuaderno de la intemperie

Página estática en HTML para personalizar y publicar con GitHub Pages.

## Personalizar

Abre `index.html` y modifica:

- El título de la pestaña en `<title>`.
- El nombre de la edición en el encabezado y el título principal.
- El fragmento dentro de `<blockquote>`.
- La playlist en el atributo `href` del enlace `Escuchar en Spotify`.
- Las fotografías: busca las direcciones `images.unsplash.com` dentro del CSS y reemplázalas por otras imágenes.

La página usa una sola dependencia de archivo: `index.html`. Las fuentes de Google Fonts y las fotografías se cargan desde internet.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages** y selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`. Guarda los cambios. GitHub mostrará allí la URL cuando termine la publicación.
